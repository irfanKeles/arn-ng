Button

arnButton styles a native <button> or <a>. The element stays what it is: type, form, href and every aria-* attribute work as they always do.

The styles come with the component; the tokens they read are part of the theme file, which the application adds once.

There is no <arn-button> element: put the attribute on the native element. A <button> without type submits its form, as it always does, so the examples write type="button".

Six variants, with the shadcn/ui names. Without variant the button is default. Use destructive for an action that deletes or cannot be undone, outline and ghost for the quieter actions next to it.

link has no fill and no border you can see; its text is underlined only on hover and while pressed. It keeps the button's height and padding, so it is not a fit for a link inside running text: use a plain <a> there.

On a <button>, disabled is the native attribute: the button cannot be focused or clicked, also inside a disabled <fieldset>. A link has no native disabled state, so on an <a> the button sets aria-disabled="true", takes the link out of the tab order and cancels its clicks (routerLink included). The link keeps its href.

Five sizes, xs to xl; the default is md. Without size the button follows the size configuration of provideArn() or the nearest arnConfig section (Configuration). Compact density makes the button lower and narrower, never below 24px (Theming).

Put an <svg> before or after the label: it takes the icon size of the button and the gap follows the size. Hide a decorative icon with aria-hidden="true". An arrow that points the way of reading gets arn-rtl-mirror, so it turns around in right-to-left pages.

iconOnly makes a square button for a single icon; give it a name with aria-label. In development a warning in the console names an icon-only button that has none. round makes the corners fully round: a circle with iconOnly, a pill with a label.

When the button takes the user somewhere, use <a arnButton> with an href or a routerLink. It is announced as a link, opens in a new tab with a middle click and follows Enter, not Space, as links do.

A count inside the label is plain content. An element with the arnButtonBadge attribute is placed on the top inline-end corner instead, ringed with the background, mirrored in right-to-left pages and hidden while it is empty. The button only places it; its look is your CSS (an arn-badge component comes later). Put the count in the button's name too, as the second example does.

The button carries the ripple directive, opened as ripple, rippleColor and rippleCentered. It is off by default and follows the ripple configuration; an empty ripple attribute turns it on for one button.

  • Native roles. A <button> is a button and an <a href> is a link; the component adds no role.
  • Focus ring. A 3px ring in --arn-ring (--arn-destructive for destructive) shows for keyboard focus; the border does not change. In forced-colors mode an outline in the system color takes its place.
  • Contrast. Text against fill is at least 4.5:1 in every variant and state, in light and dark, measured over --arn-background. A hover or pressed fill is partly transparent, so on another surface the ratio is that surface's.
  • Target size. The smallest button, xs in compact density, is still 24px high.
  • Disabled links.&ngsp;aria-disabled="true" tells assistive technology, tabindex="-1" takes the link out of the tab order (a tabindex of your own comes back when it is enabled again), and clicks are cancelled.
  • Known limit: the ripple on a disabled button. Pointer events stay on while disabled, and the browser still sends a press to a disabled button, so a button with the ripple on draws a wave when pressed while disabled. Nothing else happens.

The rules every component must meet: Accessibility.

The component has no outputs and no public methods.

The button defines none of these tokens: it reads each with the library value as the fallback. Set one on a container and every button inside follows; set it on one button and only that one changes. <size> is the button's size.

The library's rules have no specificity of their own, so a single class of yours wins over them. The same holds for a global button reset in your styles.
