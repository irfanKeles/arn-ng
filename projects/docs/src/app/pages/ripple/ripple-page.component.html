Ripple

The arnRipple directive draws a wave from the pointer when an element is pressed. It is off by default.

The directive's styles and tokens are part of the theme file, which the application adds once. Without it the wave has no style.

Put arnRipple on the element that is pressed. The element must be positioned (position: relative): the wave fills the nearest positioned ancestor, and the directive writes no style on its host. The corners follow the host's border-radius.

The ripple follows the ripple configuration: the application's provideArn(), the nearest arnConfig section, or ArnConfigService at runtime. The default is off. How the levels work: Configuration.

An empty attribute is always on.&ngsp;<button arnRipple> sets the input to true, and a value on the element is stronger than any configuration, so that button ripples even where the configuration turns the ripple off. In the same way [arnRipple]="false" is always off. Only an input that is not given (undefined) follows the configuration. Components that use the ripple will pass their own input through, so leaving it unbound there means "follow the configuration".

Clear the checkbox below: the first button stops, the other two keep their own value.

The wave is the element's text color at 12%. arnRippleColor sets another color for one element, used exactly as given: include the transparency in the value.

With arnRippleCentered the wave starts from the middle of the element, wherever it is pressed. It suits small, round targets such as icon buttons.

  • Pointer only. A mouse button, touch or pen press draws the wave; Enter, Space and a programmatic click() do not. The focus ring is the keyboard's feedback.
  • Reduced motion. With prefers-reduced-motion: reduce no wave is drawn. The preference is read on every press, so a change applies at once.
  • Hidden from assistive technology. The wave and its container carry aria-hidden="true" and take no pointer events; the element's role, name and focus do not change.
  • The element still needs a name. An icon-only button gets one with aria-label, as in the centered example.

The directive has no outputs and no public methods.

The tokens can be changed for the whole page or for one part of it; a color for a single element is arnRippleColor.
