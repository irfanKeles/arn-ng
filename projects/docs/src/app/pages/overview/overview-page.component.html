arn-ng

An Angular UI component library built on Angular CDK. Its visual language follows shadcn/ui.

Status

@arn-ng/ui is in early development (0.x) and has not been published to npm yet. This site is built in the same workspace and consumes the library the way an application would.

What exists today

  • Theme. Design tokens in @arn-ng/ui/theme.css, with light and dark color schemes, five control sizes and two densities.
  • Configuration. provideArn(), the arnConfig directive and ArnConfigService in @arn-ng/ui/core set size, density, color scheme, direction and locale for the application, a section or a single component.
  • Locales. English texts are built in; Turkish ships as @arn-ng/ui/locales/tr.
  • Overlay. ArnOverlayService is the shared foundation for dialogs, menus and tooltips.
  • Ripple. The arnRipple directive in @arn-ng/ui/ripple.

Components come next; none has been released yet.

Try the settings

The controls in the header change the library's configuration through ArnConfigService. Theme, direction and density apply to this whole site immediately, because the site is styled with the library's tokens. Language switches the library's locale and built-in texts, not the language of this site.
