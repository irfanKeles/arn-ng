# Sürümleme ve kalite (eski §15)

- Semver. Her değişiklik changelog'a yazılır. Kırıcı değişiklik major'a gider (1.0.0'dan sonra).
- Sürüm ve changelog: Changesets. Sürümün tek kaynağı `projects/ui/package.json`; kök `package.json` sürümü ilgisizdir. Akış: `npm run changeset` (değişikliği tarif et) → sürüm çıkarırken `npm run version-packages` (sürümü artırır, `projects/ui/CHANGELOG.md`'yi yazar) → `npm run build:ui` (sürüm ve changelog `dist/ui`'ye geçer). Durum: `npx changeset status`.
- 0.x kuralı: kırıcı değişiklik ve yeni özellik `minor`, düzeltme `patch`. `major` changeset YAZILMAZ (0.x'i doğrudan 1.0.0 yapar); 1.0.0 ayrı karardır. 0.1.0'a kadar changeset yazılmaz, ilk sürüm tek changeset'le çıkar.
- Dependabot PR'ları changeset istemez. İstisna: PR `projects/ui/package.json`'daki `dependencies`/`peerDependencies`'e dokunuyorsa changeset elle eklenir.
- Yayın `dist/ui`'den yapılır. `changeset publish` KULLANILMAZ (kaynak klasörü yayınlar).
- Yerel paket testi: Verdaccio ile, adımlar ve güvenlik kuralları [local-package-test.md](../local-package-test.md)'de. `exports`, entry point veya `projects/ui/package.json` değişince ve her yayından önce çalıştırılır. Gerçek registry'ye asla deneme yayını yapılmaz.
- Node: `.nvmrc` `22`, `package.json` `engines.node` `^22.22.3`. `engine-strict` kapalı.
- Lint: `npm run lint` = ESLint (flat config, `eslint.config.mjs`: angular-eslint + typescript-eslint `strictTypeChecked`, şablon a11y kuralları) + Stylelint (`.stylelintrc.json`: `::ng-deep`, `!important` ve yön-bağımlı CSS yasak, ui'da token adı `--arn-*`). [angular.md](angular.md) ve [styling.md](styling.md) kurallarının çoğu burada hata olarak zorlanır. Kural kapatmak veya `eslint-disable` yazmak karar günlüğüne gerekçe ister.
- Format: Prettier (`npm run format`, `npm run format:check`). Markdown ve `.claude/` kapsam dışı. Satır sonu LF (`.gitattributes`).
- Lint ile zorlanamayan, incelemede elle bakılan kurallar: `subscribe` temizliği, `innerHTML`, entry point'ler arası döngüsel bağımlılık, sabit renk/px.
- Birim test: Vitest 5.1 browser mode, Playwright Chromium (`@vitest/browser-playwright`), builder `@angular/build:unit-test`; iki projede de `browsers: ["chromium"]`, `browserViewport: "800x600"` (`angular.json`). ui'nin derlemesi ayrı `test-build` hedefinden gelir (`@angular/build:application`, `tsconfig.spec.json`, `polyfills: []`, `styles: ["projects/ui/theme.css"]`); docs testi `docs:build:development,testing` hedefini kullanır (`testing` konfigürasyonu `polyfills: []`). Komutlar: `npm test` (ui, izleme modu), `npm run test:docs`, `npm run test:ci` (`ng test --watch=false --headless --coverage`, tüm projeler, coverage → `coverage/`). Playwright Chromium'u yerelde bir kez kur: `npx playwright install chromium`.
- Çok tarayıcılı koşu: ui ayrıca Firefox ve WebKit (Playwright) ile koşar: `npm run test:firefox`, `npm run test:webkit` (`ng test ui --browsers=<x>`, coverage yok: V8 sağlayıcısı yalnız Chromium'da; docs yalnız Chromium). Kurulum: `npx playwright install firefox webkit`. Chromium'a özgü CDP (`cdp()`) Chromium'da kalır; diğerlerinde aynı işi `projects/ui/vitest-base.config.mts`'teki browser command'ları yapar (`runnerConfig`; `arnMouse` → `page.mouse`, `arnReducedMotion` → `page.emulateMedia`, `arnAriaSnapshot` → Playwright ARIA snapshot'ı, tarayıcının ağacı değil). Dallanma `projects/ui/testing/browser.ts` ve `pointer.ts`'te. Bir motorda ölçülemeyen test sessizce düşürülmez: çalışma zamanı denetimiyle `skip(koşul, 'neden')`, adı raporda kalır. Belgede ve kodda "Safari" değil "WebKit (Playwright)" yazılır: yerel koşu Windows'ta Playwright'ın WebKit portu, Safari değil. Playwright güncel Firefox/WebKit verir, tarayıcı tabanını doğrulamaz.
- Testler **zoneless** koşar: zone.js test ortamına yüklenmez (`polyfills: []`); setup dosyaları (`projects/ui/testing/test-setup.ts`, `projects/docs/src/test-setup.ts`) her teste `provideZonelessChangeDetection()` verir (Angular 20.2'den beri `@publicApi`; docs uygulaması da kullanır). Zone'a yaslanan kod testte kırılır. Setup ayrıca `<html lang>`'ı kaldırır: Vitest'in test sayfası `lang="en"` ile gelir, spec'ler ise kütüphanenin `lang` yazmadığını sınar (`no-restricted-globals` için satır içi `eslint-disable-next-line`).
- **Her bileşen spec'inde axe testi zorunlu:** `await expectNoA11yViolations(fixture.nativeElement)` (`projects/ui/testing/a11y.ts`). Yardımcı public API'nin parçası değildir, entry point'lerden export edilmez; spec'ler göreli yolla import eder.
- Test API'si: `describe/it/beforeEach/afterEach/expect` ve Vitest'in `vi` yardımcıları (`vi.fn`, `vi.spyOn`, `vi.useFakeTimers`) serbesttir (`types: ["vitest/globals"]`). Jasmine global'leri (`jasmine.*`, `spyOn`, `expectAsync`, `fail`, `fit/fdescribe/xit/xdescribe`…) ESLint'te hatadır. `fakeAsync/waitForAsync/tick/flush/flushMicrotasks` ESLint'te yasaktır: zone.js gerektirirler, testler zoneless koşar ve zone.js yüklü değildir.
- Spec dosyaları kaynağın yanında durur (`*.spec.ts`); `projects/ui` altındaki her klasör taranır (`sourceRoot`: [architecture.md](architecture.md)).
- CI (`.github/workflows/ci.yml`, `ubuntu-24.04`): `main`'e push ve her PR'da, Node sürümü `.nvmrc`'den, sırayla `npm ci` → `npx playwright install chromium` → `npm run lint` → `format:check` → `build:ui` → `build:docs` → `test:ci` (axe testleri dahil). Paralel `browsers` işi (matris `firefox`, `webkit`): `npm ci` → `npx playwright install <x>` → `npm run test:<x>`. Yerelde aynı komutları aynı sırayla çalıştır (Playwright kurulumu bir kez yeter); PR açmadan önce hepsi geçmeli.
